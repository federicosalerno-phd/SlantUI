What this is

A window built on SlantUI and nothing else. The band above, the rail of steps, this panel and every control in it come from the library's five stylesheets and four scripts.

The file

Nothing is read off disk here. The card on the stage takes a drop and hands the name to the toolbar, which is where fitOneLine() shortens a long one and keeps the extension.

Run
A slot, a signal, and the two ways of waiting
The job

Run calls a slot on the bridge. Python answers with a signal every 60 ms, and the card in the middle follows it. The work itself is a timer counting, which is all an example needs; the round trip is the same when the work is real.

Normal (2.4 s)
The other wait

A job with no percentage to report gets the spinner instead. Both sit on the same scrim, which leaves the title bar and the rail on screen, so the window never turns into a black rectangle.

The wait that stays in the panel

Not every job earns the scrim. One that leaves the rest of the window usable says so where it runs: the same ring, small enough to stand in a line of text, and a band crossing the track when there is no percentage to give. A bar parked at two per cent would read as stuck.
