Rotation
What it does

Turns the model's own reference frame. Everything placed after it is placed in the frame you leave here, so the view you set is the view the next step measures in.

How to use it

Drag the strip for a gentle turn, hold an arrow to go faster the longer you hold, or type the angle. Reset puts the frame back where the file had it.

Keys

R turn, then grab the ring
